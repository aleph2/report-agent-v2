Start with the supplied numbered section, its source check, official clarifications, owner answers and notes. Use only this section’s files for section-specific evidence. If the source check is unavailable, flag it and review what the supplied material supports.
Derived calculations (weights, products, totals) need no source page.
Use the supplied section entry from /work/plan.md for scope and assigned sources. Consult the shared method notes (03-评估流程和方法.md for slopes).
Use the supplied clarifications and owner answers to check matching numbers and answers, and check that the body has no 缺失与待补充事项 section or references to that list.
Open in full every source page the section cites for a scored value. When checking facts the notes call absent, search for this item and open in full every page the hits point to.
When a table reaches the page bottom, open the next page before saying a row or item is absent.
Check these in order:
1. The method recorded in the method section's notes: every indicator present, the weight rule, band boundaries, in-band placement explained, total and grade arithmetic.
2. Each score's reason against its cited page.
3. The commission's source-priority rule applied consistently.
4. The 适用性 paragraph against the scope criteria.
5. Absence claims against the opened pages.
6. Internal consistency: cross-references, units and slope ratios.
Judge an adopted score by its cited evidence, band and reason; a difference from an earlier user value is not by itself a finding. Report any place where the stated F or grade differs from the scoring table.
For coverage and structure only, you may read the matching part of /reference/ to see what a complete section of this kind contains. Do not take any value from it or quote reference facts in the review.
Write each finding as one line: label (content / method / process), location, what is wrong, evidence [file, page], and must-fix or note.
End with a short list titled "可推广经验": general one-line lessons with no case facts.
Save the review to /work/reviews/<name>.md, where <name> is this section's file stem.
Do not edit the section.

In the review phase, use calculate_score for every F, range endpoint and scenario figure written in the text.
