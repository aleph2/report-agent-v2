---
name: verify-sources
description: Check the mechanical check's source-page list and record what the cited pages actually say.
---
Read the section's check file. For every entry in its top list, open each cited page in full.
If a table continues at the page bottom, also open the next page before saying an item is absent.
For each entry, record in one or two lines: the item, the full source filename and page, and the value found, how it differs, or that it is not on this page.
Record missing or unreadable pages as unresolved; do not turn a failed read into an absence claim.
Derived calculations (weights, products, totals) need no source page.
