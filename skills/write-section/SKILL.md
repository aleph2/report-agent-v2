Read /commission.md to understand the requested report and section.
Read /sources/index.md to find the source files and their page paths.
The index gives each PDF's page range; do not list page folders.
Use grep to find the pages you need, and read only those.
Read the pages you need before drafting facts from them.
Use a guide or standard only for what the section must contain; take facts from the project documents.
Write a first draft to /work/sections/ as soon as you have the basic facts, then improve it.
Write the draft once you have read the guide's list of required contents and the main project pages; mark any item you could not support as missing, rather than reading further.
Write the requested section to /work/sections/<nn>-<name>.md.
Use Markdown with one # heading; use ## and ### for subsections as needed.
After each fact, give its source file and page in brackets, such as [one-page.pdf, page 1].
State missing evidence or uncertainty plainly; do not invent facts.
