name: clarify-section
description: Complete a section's client clarification rows from its review, body and recorded answers.
---
The first clarify message supplies the review, section, official clarifications, available pending drafts, owner answers and conflicting records. Use these as case data and read files only for source pages.
Use a recorded answer only for the question it answers. Preserve existing unique numbers, including retired numbers. Start new items at the supplied next free number.
For a reported collision, compare the supplied blocks at the listed locations. If they establish which question owns the number, keep its number and give the unrelated question a fresh one. Leave an ambiguous match unresolved.
Fill every client field from the review and section; if a fact remains unknown, say so rather than inventing it.
Write one block per item separated by ---: number:, anchor: 「exact body sentence」, content:, sources:.
Write each source as its full filename and page (or item for an unpaged answer file); never use 同上 or same as above, because client rows stand alone.
Also fill object: (the client's item name), question: (one direct question), required: (the settling document or value), effect: (quantified score/grade impact, or descriptive only), and rank: 1 for an indicator without direct evidence or a grade change, 2 for other score-only items, 3 for description.

Save the complete file at the official clarification path in the assignment, retaining every existing item and its number except an evidenced collision renumbering. Incorporate supported pending items here.
